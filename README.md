# 🎨 Pixel Pop Studio (High-Resolution Pixel Art & Color-by-Number Studio)

เว็บแอปพลิเคชันแบบ Single-File (HTML, CSS, Vanilla JavaScript) สำหรับแปลงรูปภาพเป็นภาพพิกเซลความละเอียดสูง และสร้างตารางตัวเลขสี (Color-by-Number / Bead & Cross-Stitch Pattern Studio) ในธีม Neo-Brutalism Cartoon สดใสสวยงาม

---

## 🌟 ฟีเจอร์เด่น (Key Features)

### 🖼️ โหมดที่ 1: แปลงภาพเป็นพิกเซล (High-Density Image to Pixel Art)
- **รองรับทุกสัดส่วนภาพ**: อัปโหลดไฟล์ภาพ PNG, JPG, WEBP รองรับตั้งแต่ภาพจัตุรัส ภาพแนวตั้ง จนถึงภาพแนวยาว/พาโนรามาพิเศษ (180x35, 250x50 หรือสูงสุดถึง 500x500 ช่อง)
- **ปรับขนาดพิกเซลอิสระ**: กำหนด Width x Height ได้ตามต้องการ พร้อมปุ่มล็อกอัตราส่วนภาพ (Lock Aspect Ratio) และปุ่มสัดส่วนด่วน
- **ระบบเส้นตาราง 3 ระดับ (Multi-Level Hierarchical Grid Lines)**:
  1. *เส้นตารางย่อย (Minor Grid)*: เส้นบาง 1x1 ช่อง
  2. *เส้นบล็อกหลัก (Major Block Grid)*: เส้นสีดำหนาปานกลางแบ่งทุก 5x5, 6x6 หรือ 10x10 ช่อง
  3. *เส้นแบ่งโซนใหญ่ (Section Divider Line)*: เส้นเน้นสีพิเศษตัดทะลุทุก 20, 25, 30 หรือ 50 ช่อง สำหรับแบ่งช่วงภาพแนวยาว
- **กำหนดโค้ดสีตามใจ (Custom Color Palette)**:
  - หากไม่ใส่โค้ดสี: ระบบใช้สีธรรมชาติของภาพ พร้อมตัวเลือกลดทอนสี (Color Quantization: 8, 16, 32, 64 สี)
  - หากกำหนดโค้ดสีเอง: ระบบบังคับจับคู่เฉพาะสีที่กำหนดด้วยสูตรความต่างของสีถ่วงน้ำหนักสายตามนุษย์ (**Perceptual Redmean Distance**)
  - มีชุดสีสำเร็จรูปให้เลือก: บีดส์ 24 สี, PICO-8, GameBoy, พาสเทล
- **ส่งออก High-Res PNG**: ปรับขนาด Pixel Cell ตอนบันทึกได้ (16px, 20px, 28px, 36px) เส้นตารางและเม็ดสีคมชัดไม่เบลอ พร้อมปุ่มส่งต่อไปโหมด 2 ทันที

### 🔢 โหมดที่ 2: ตารางตัวเลขสี (High-Res Pixel to Number Mapper)
- **ระบบตั้งค่าโค้ดสีประจำตัวเลข (1, 2, 3...)**: เพิ่มสีและกำหนดรหัสสี HEX ได้ไม่จำกัด
- **ดึงสีอัตโนมัติ (Auto-Extract Palette)**: กวาดหาสีทั้งหมดในภาพพิกเซลมาเรียงเป็นลำดับ 1, 2, 3... ให้ทันที พร้อมคำนวณจำนวนเม็ดและเปอร์เซ็นต์
- **Smart Center-Cell Sampling**: เมื่อนำเข้าภาพพิกเซลที่มีเส้นตารางสีดำติดมา ระบบจะอ่านเฉพาะกึ่งกลาง 40% ของช่อง เพื่อไม่ให้เส้นตารางสีดำเดิมรบกวนการคำนวณสี
- **3 โหมดการมองเห็น (Display Modes)**:
  1. *Number-Only Blueprint*: ตารางตัวเลขล้วนบนพื้นขาว เหมาะสำหรับพิมพ์เป็นแบบระบายสีหรือแพทเทิร์นปัก
  2. *Tinted Color + Numbers*: สีพื้นหลังจางโปร่งแสง 35% พร้อมตัวเลขชัดเจน
  3. *Full Color + Numbers*: สีจริงคมชัด พร้อมตัวเลขปรับสีขาว/ดำอัตโนมัติตามความสว่างพื้นหลัง (Contrast YIQ)
- **ระบบไฮไลต์ตัวเลข (Number Highlighter)**: คลิกที่หมายเลขใดในตารางสี เพื่อเรืองแสงเน้นเฉพาะช่องหมายเลขนั้นบนหน้าจอ
- **ส่งออก Ultra-HD PNG & CSV**:
  - ส่งออกภาพความละเอียดสูง (Cell Size 24px - 40px) พร้อมแนบ **ตารางคู่มือสี (Color Legend)** ท้ายภาพ
  - ส่งออกเป็นไฟล์ **CSV / Excel Grid** สำหรับนำไปเปิดในตารางคำนวณ
  - รองรับการสั่งพิมพ์ทันที (`window.print()`)
